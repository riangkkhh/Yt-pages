ניקוי אוטומטי של סרטונים חסומים

כשהאתר מוצא סרטון חסום, הוא יכול למחוק את הקישור שלו מהקובץ videos.txt בגיטהאב. לשם כך צריך מפתח גישה (טוקן), שנשמר רק בדפדפן הזה:

  1. בגיטהאב: תמונת הפרופיל ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. בחלק Repository access בוחרים Only select repositories ואז את הריפו של האתר.
  3. בחלק Permissions ← Repository permissions ← Contents בוחרים Read and write.
